# MindMap 🧠✨

**Mental Health Well-being Surveillance and Assessment Platform for Teens and Students**

A comprehensive Next.js application designed to support mental health through intelligent journal analysis, personalized music therapy, and AI-powered mental health assistance.

## 🌟 Features

### 📝 Journal-Based Mental Health Assessment
- **Smart Analysis**: Advanced surveillance and assessment of mental well-being through journal entries
- **Mood Tracking**: Monitor emotional patterns and mental health trends over time
- **Privacy-First**: Secure and confidential journal storage with user privacy protection

### 🎵 Personalized Music Therapy
- **Solfeggio Frequencies**: Therapeutic music recommendations using specific frequencies to target different brain areas
- **Brain-Targeted Therapy**: Customized audio experiences designed to promote mental wellness
- **Frequency-Based Healing**: Leverage scientifically-backed sound frequencies for emotional regulation

### 🤖 AI Mental Health Assistant
- **Depression Support**: Intelligent guidance and support for students experiencing depression
- **Goal Generation**: Personalized mental health goals and actionable steps for improvement
- **24/7 Availability**: Always-accessible mental health companion for immediate support

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm, yarn, or pnpm

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Shades-en/MindMap.git
   cd MindMap
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application.
